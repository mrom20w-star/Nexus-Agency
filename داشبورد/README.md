# لوحة تحكم الأدمن المستقلة (React) — Nexus Agency

هذا المجلد (`داشبورد`) يحتوي على **لوحة تحكم الأدمن كاملة** جاهزة للرفع والتشغيل مباشرة على أي استضافة.

---

## طريقتين للرفع والتشغيل فوراً

### 1) الرفع المباشر (بدون أوامر أو Node.js) — مجلد `dist/`
مجلد `dist/` جاهز ومبني بالفعل للإنتاج، ويحتوي على:
- `index.html` + ملفات `assets/`
- `.htaccess` (لتشغيل الروابط على استضافات cPanel / Apache)
- `vercel.json` (لتشغيل الروابط على Vercel)
- `admin-api.php` (لحفظ البيانات تلقائياً في ملف `data/hpay-db.json` إذا كانت الاستضافة تدعم PHP)

**الخطوات:**
1. ارفع جميع الملفات الموجودة داخل `داشبورد/dist/` إلى مجلد الاستضافة (`public_html/` أو مجلد فرعي مثل `public_html/admin/`).
2. افتح الرابط في المتصفح مباشرة.
3. عند الفتح لأول مرة، ستظهر لك شاشة **تفعيل كلمة مرور الإدارة** لتعيين كلمة مرور خاصة بك (أو يمكنك ضبط متغير البيئة `ADMIN_PASSWORD` على السيرفر).

---

### 2) البناء من الكود المصدري (Vercel / Netlify / GitHub / Local)
إذا أردت تعديل الكود أو نشره عبر Git:
```bash
npm install
npm run build
```
الناتج سيخرج تلقائياً في مجلد `dist/`.

---

## المميزات المتوفرة داخل اللوحة
- **اللاعبين والحسابات**: إنشاء حسابات لاعبين برصيد `0.00 ج.م` وID عشوائي (`PL-XXXXXXXX`)، تعديل الأرصدة وكلمات المرور، وتفعيل/إيقاف الحسابات.
- **طلبات السحب والإيداع**:
  - إرسال طلبات سحب لرسائل اللاعب (يُخصم عند موافقة اللاعب).
  - عمل إيداع فوري للاعب عبر الجيميل أو اليوزر نيم (اختيار الجيميل + كتابة الجيميل/اليوزر + المبلغ + طريقة الإيداع + ملاحظة).
- **الإيداعات والرسايل**: إرسال رسائل مباشرة لبروفايل اللاعبين + تنفيذ/مراجعة الإيداعات الفورية.
- **إعدادات المنصة والصرف**: اسم المنصة مثبّت (`Nexus Agency`) مع تعديل سعر الدولار مقابل الجنيه وتغيير كلمة مرور الأدمن.
- **الأمان والتشغيل**: حفظ مشفّر لكلمات المرور عبر PHP (`admin-api.php`) أو تخزين محلي آمن في المتصفح مع دعم ربط سحابي اختياري عبر متغيرات البيئة.
